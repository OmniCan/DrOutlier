### 2. Functional Profile Page
**URL**: https://www.droutlier.com/profile

#### Features:
✅ **Upload Profile Photo** - Click camera icon (max 5MB)  
✅ **Edit Name** - Update first and last name  
✅ **Mobile Number** - Add phone with country code dropdown  
✅ **Change Password** - Secure password update  
✅ **Edit/View Modes** - Toggle between viewing and editing  

#### How to Use:
1. Click **Profile** in user dropdown menu (top-right)
2. Click **Edit Profile** to make changes
3. Update fields as needed
4. Click **Save Changes** or **Cancel**
5. For password: Click **Change Password**

### 3. Functional Bookmarks Page
**URL**: https://www.droutlier.com/bookmarks

#### Features:
✅ **7 Content Categories** - Notes, Spotters, OSCE, Quizora, AI-Rad, Practical Essentials, Watch & Learn  
✅ **Accordion Interface** - Expand/collapse each category  
✅ **Summary Stats** - Total bookmarks, active categories, most saved  
✅ **Card View** - Clean cards with title, description, date  
✅ **Quick Actions** - View content or remove bookmark  

#### How to Use:
1. Click **Saved/Bookmarks** in user dropdown menu (top-right)
2. View summary statistics at top
3. Click any category to expand and see bookmarks
4. Click **View** button to open content
5. Click trash icon to remove bookmark

## ⚠️ Important Notes

### Profile Page
- **Email cannot be changed** (security measure)
- **Photo limit**: 5MB maximum
- **Phone number**: Must be 10 digits
- **Password**: Minimum 6 characters
- **Cancel**: Discards all changes without saving

### Bookmarks Page
- **Auto-loads**: All bookmarks fetch automatically
- **Parallel loading**: Faster load times
- **One accordion**: Only one category open at a time
- **Remove bookmark**: Cannot be undone (re-bookmark from original page)

## 🐛 Troubleshooting

### Profile Photo Won't Upload
- Check file size (must be < 5MB)
- Ensure file is an image (jpg, png, gif)
- Try a different browser

### Bookmarks Not Loading
- Check internet connection
- Refresh the page
- Clear browser cache
- Re-login to account

### Password Change Failed
- Verify current password is correct
- Ensure new password is 6+ characters
- Make sure passwords match

### Country Code Not Showing
- Refresh the page
- Check if API is accessible
- Try different browser
